# SRE Linux Diagnostics

A lightweight Linux diagnostics toolkit for troubleshooting common production-system issues.

## Overview

This project provides Bash and Python utilities to collect basic system health information during troubleshooting and incident investigation.

## What It Checks

- Hostname and operating-system information
- System uptime
- CPU information
- Memory utilization
- Disk utilization
- Network interfaces
- Listening TCP/UDP ports
- Top CPU-consuming processes
