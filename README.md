# SRE Linux Diagnostics

A lightweight Linux diagnostics toolkit for troubleshooting common production-system issues.

## Overview

This project provides Bash and Python utilities to collect basic system health information during production troubleshooting.

## Features

- Hostname and OS information
- Disk utilization
- Memory utilization
- Network interfaces
- Listening TCP/UDP ports
- Top CPU-consuming processes
- Basic system health checks
- Linux production troubleshooting automation

## Technologies

- Linux / Unix
- Bash
- Python
- Git / GitHub
